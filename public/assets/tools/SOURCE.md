# Tool icon sources

These small brand marks label the owner's selected software and AI tools. They are served locally, with visible text labels; decorative images have empty alt text. Brand marks remain the property of their respective owners.

- Creative software: [Devicon](https://github.com/devicons/devicon), commit `4fbcc685c9a85434bc01b1c236c9076f54806236`, original SVGs from `icons/{name}/{name}-original.svg`. Canva AI uses the same Canva mark. License: `LICENSE-devicon.txt`.
- AI tools: [Lobe Icons](https://github.com/lobehub/lobe-icons), commit `cc639da879a3f404f5ded8ec41cdfdc63abd8317`, SVGs from `packages/static-svg/icons/{name}.svg` (Codex, Gemini, Nano Banana, Midjourney, Claude Code). License: `LICENSE-lobe-icons.txt`.

SVG files are unmodified. No icon library runtime or remote image requests are required.
