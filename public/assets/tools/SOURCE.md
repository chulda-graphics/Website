# Tool icon sources

Small brand marks identify selected software and AI tools. Files are served locally, with visible labels and empty decorative alt text. Brand marks remain the property of their respective owners.

- Adobe refreshed 2026 icons: unmodified SVGs downloaded from official Adobe product pages on 2026-10-26. Base URL `https://www.adobe.com/cc-shared/assets/img/product-icons/svg/`; After Effects: `after-effects-40.svg`, Premiere Pro: `premiere-pro.svg`, Photoshop: `photoshop-40.svg`, Illustrator: `illustrator.svg`. Adobe describes the refresh at https://adobe.design/ideas/behind-the-design-adobe-s-updated-app-icons . These brand assets are not covered by the library licenses below.
- Blender and Canva: [Devicon](https://github.com/devicons/devicon), commit `4fbcc685c9a85434bc01b1c236c9076f54806236`, `icons/{name}/{name}-original.svg`. License: `LICENSE-devicon.txt`.
- Codex, Gemini, Claude: [Lobe Icons](https://github.com/lobehub/lobe-icons), commit `cc639da879a3f404f5ded8ec41cdfdc63abd8317`, `packages/static-svg/icons/{name}-color.svg`. Claude Code uses the coloured Claude mark. License: `LICENSE-lobe-icons.txt`.
- Higgsfield: [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons), commit `d3b9234dd56f3af5862f06741f0dce101193b3df`, `svg/higgsfield.svg`, original lime-green app icon. License: `LICENSE-dashboard-icons.txt`.

SVG artwork is unmodified; Adobe file line endings are normalized. No icon library runtime or remote image requests are required.
